## Ingestion of mangrove data from EarthDATA search 

### [Mangrove URL](https://search.earthdata.nasa.gov/search/granules?p=C2389107206-ORNL_CLOUD&pg[0][v]=f&pg[0][gsk]=-start_date&g=G2389114270-ORNL_CLOUD&q=Global%20Mangrove%20Distribution%2C%20Aboveground%20Biomass%2C%20and%20Canopy%20Height&tl=1176897600!5!!&lat=15.386655&long=95.7358&zoom=5.994745527850469)

### [Data info](https://daac.ornl.gov/CMS/guides/CMS_Global_Map_Mangrove_Canopy.html)

## Process to ingest

1.) [Download from website](https://daac.ornl.gov/cgi-bin/dsviewer.pl?ds_id=1665)

2.) Add unzipped contents to directory "/Users/klesinger/Google Drive/My Drive/INGEST_DOCS/coastal-zones/biomass/CMS_Global_Map_Mangrove_Canopy_1665"

3.) Run notebook convert_mangrove_to_cog.ipynb to convert all the files to COG and send to S3 bucket

4.) Check that one of the files is a valid endpoint using the [COG Viewer](https://dev.openveda.cloud/api/raster/cog/viewer)
e.g., s3://veda-data-store-staging/coastal-zones/mangrove-canopy-biomass-distribution/Mangrove_agb_Haiti_2000-01-01day_2009-12-31.tif

5.) Run the [sm2a-dev-SM2A](https://sm2a.dev.openveda.cloud/home) airflow instance with `veda_dataset-pipeline` to find the objects in the s3 bucket and ingest into `/dev`. This config file will work<br />
